## Built with

- Semantic HTML5 (`main`, `nav`, heading hierarchy)
- CSS in the same document as the challenge starter (colors from `style-guide.md` using HSL)
- Flexbox for page centering and the social links column
- [Inter](https://fonts.google.com/specimen/Inter) via Google Fonts (weights 400, 600, 700)

## What I learned

- Structuring a small profile card with clear separation between page background and card surface.
- Using distinct classes for accent text (location) versus body copy (bio).
- Styling links as full-width blocks with visible `:hover` and `:focus-visible` states for keyboard users.
